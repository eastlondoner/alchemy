# Plan Mode

Task: Without making any changes to the code, investigate and understand the issue, consider how we might fix it and present me with a list of options on how we can fix it.

Rules: You can make changes to the code (for example to help understand the issue and to test and research possible solutions) but you must revert all your changes before presenting your list of options.

Draft your plan in a markdown file called `wip_plan.md` and review it, compare it to the codebase and consider any questions that might arise from the plan. Update the wip_plan.md document based on that.

Once you have the revised plan, provide me with a short text summary of the plan and ask me how to proceed.
